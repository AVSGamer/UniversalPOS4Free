# 🏪 UniversalPOS4Free

**UniversalPOS4Free** is a fully open-source, highly adaptable **Point of Sale (POS) system** designed to serve any business vertical—from small retail shops to large-scale hospitality environments.

---

## 🚀 Target Platforms & Roadmap

The software is systematically architected to run across a wide array of deployment ecosystems:

* **🌐 Web Version** — Cloud-hosted or locally deployed in-browser dashboards.
* **🤖 Android App** — Mobile point-of-sale capabilities for handheld devices and tablets.
* **🐧 Linux Version** — Stable, low-overhead deployments tailored for dedicated POS terminals.
* **🪟 Windows Version** — Native desktop support for standard enterprise hardware.
* **🍏 macOS Version** — *Planned conditionally pending community funding, sponsorship, or strategic developer support.*

---

## 🔒 Architectural Blueprint (Conception: October 12, 2026)

### 📋 Global System Variables & State Control
* **`firstRun` (`int`)** — A strict operational state countermeasure. Safeguards data by preventing accidental overwrites or malicious factory-reset exploits, ensuring critical records and administrative layouts persist.
* **`loggedInAccLevel` (`dynamic`)** — An open-ended array structure allowing administrators to provision infinite custom account permission tiers. Includes runtime validation bounds checking to prevent privilege escalation.
* **`secretKey1` (`string`)** — Core baseline string utilized for foundational system integrity verification (e.g., standard MD5 or SHA hashing frameworks).

---

## 🛡️ Dynamic Custom Encryption Engine

To preserve security in an open-source paradigm, the default cryptographic keys and algorithms visible in this repository serve strictly as structural templates. **UniversalPOS4Free** empowers administrators to compile an entirely custom, obfuscated security layer that lives solely on their local deployment.
